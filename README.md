# Estudos de Django e Python
Repositório dedicado aos meus estudos práticos de Python|Django|HTML|CSS|JS.

## 🚀 O que aprendi neste projeto:
- **Arquitetura e Fluxo de Dados:** Compreensão profunda do ciclo `HTML > URLs > Views > Models > ORM > Banco de Dados`.
- **Mapeamento de Rotas (urls.py):** Configuração de caminhos e nomes de rotas para direcionar requisições GET e POST.
- **Lógica de Negócio (views.py):** Captura e tratamento de dados brutos e limpos (`is_valid`), atuando como intermediário entre o banco e o usuário.
- **Modelagem de Dados (models.py):** Estruturação e definição de tipos de campos, garantindo a integridade no banco de dados.
- **Formulários Dinâmicos (forms.py):** Uso de `ModelForm` para vínculo direto com modelos e formulários nativos como `UserCreationForm` e `AuthenticationForm`.
- **Autenticação e Sessão:** Implementação de login e logout para controle de acesso do usuário.
- **Interface e UX (HTML):** Criação de templates para interação com o usuário e estilização via CSS para melhor experiência.
- **POO e Herança:** Aplicação de herança em classes de Models e Forms para reaproveitamento de código e lógica segura.
- **Integração Django + JS:** Uso de JavaScript para capturar dicionários enviados pela View, permitindo o tratamento dinâmico de dados no front-end.

## 🛠️ Como rodar o projeto:
1. Instale as dependências: `pip install -r requirements.txt`
2. Rode o servidor: `python manage.py runserver`
